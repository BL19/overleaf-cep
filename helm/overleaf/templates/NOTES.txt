To access Overleaf, you can use port-forwarding:

Then open http://localhost:8080 in your browser.

After deployment, you may need to create an admin user:

1. Get a shell in the web pod:
   $ kubectl exec -it deployment/{{ include "overleaf.fullname" . }}-web -n {{ .Release.Namespace }} -- /bin/bash

2. Create an admin user (inside the pod):
   $ cd /overleaf/services/web && node modules/server-ce-scripts/scripts/create-user --admin --email=admin@example.com
